# Paper source (CVPR 2027 format)

`main.tex` + `sec/*.tex` + `fig/` + `main.bib`, built on the official CVPR author kit (`cvpr.sty`,
`ieeenat_fullname.bst`, downloaded from github.com/cvpr-org/author-kit on 2026-11-03).

## Build

No TeX distribution is installed on the Windows box, so compile on Overleaf (upload the `paper/` folder as a
project; compiler pdfLaTeX) or with any TeX Live:

```
cd paper
latexmk -pdf main.tex
```

The review version is selected by `\usepackage[review]{cvpr}` in `main.tex`; switch to `\usepackage{cvpr}` for
camera-ready and fill in the author block.

## Figures

`fig/schematic.pdf`, `fig/main_result.pdf` and `fig/homing.pdf` are generated from `results/` by

```
PYTHONPATH=. python scripts/make_paper_figs.py
```

so they stay in sync with `results/summary.md`. `fig/env_*.png` and `fig/wm2cx_connectome_*.png` are renders from
`results/`.

## Numbers

Every number in the text comes from `results/summary.md` (regenerated by `scripts/summarize.py`) and the JSON files
under `results/hd`, `results/homing`, `results/goalnav`, `results/bench`, `results/realvid_pilot`; the prose draft
they were taken from is `docs/results_draft_path_integration.md`.

## Before submission

- Verify every entry in `main.bib` against the publisher page (author lists were written from memory and are
  abbreviated with "and others" in places).
- Check the page limit (8 pages + references for CVPR); the supplement in `sec/X_suppl.tex` is appended after
  `\clearpage` and must be split into a separate PDF for submission.
- Fill the LLM-usage and licence statements required by the CVPR policy (FlyWire data: CC-BY-NC 4.0).
