\begin{abstract}
Insects keep a heading and a home vector for seconds in darkness using a few thousand neurons whose wiring is now known
synapse by synapse. We ask whether that wiring is a useful prior for a modern video world model. We distil the latent
dynamics of \vjepa (ViT-B) into a leaky recurrent student whose \emph{only} recurrent connections are the 91,663 signed
synapses among 6,935 neurons of the \flywire \emph{Drosophila} connectome, trained purely to predict the teacher's next
latent under random blackouts of the visual input. Against controls that fix neuron count, edge count, region structure,
Dale's-law signs and parameter count, and against a parameter-matched GRU and a parameter-matched causal transformer
of the kind used by current latent world models, the connectome-wired student is \emph{not} the best predictor: the
GRU is \nGruBetterArena\,\% better and the transformer \nTfBetterArena\,\%. What the wiring buys is a path-integrating
state. During 8 blind steps a ridge probe reads heading from the connectome state to \nConnArenaHd\degree\ median error
and position to $R^2$\,\nConnArenaPos, against \nGruArenaHd\degree\ and \nGruArenaPos\ for the GRU and
\nTfArenaHd\degree\ and \nTfArenaPos\ for the transformer; an MLP probe widens the gap, the code survives 16 dark
steps, it transfers to a raycast twin of Midtown Manhattan, and it persists when turn angles are made continuous so
that the action record no longer determines heading. Replacing the shared linear input map by a cross-attention
encoder, which removes two thirds of the sparse students' parameters, changes neither finding; adding one attention
layer over cell-type tokens to the connectome recurrence tests what the sparse graph lacks. Sparse random and
block-shuffled wirings of the same size form the code too, \nConnBlockGapArena\ to \nConnBlockGapArenaDarkSixteen\degree\ worse,
so the result is a property of connectome-scale sparse signed recurrence, with a small and consistent bonus for the
real synapse list. A linear readout of the state drives blind homing well above a random-action floor but far below a
dead-reckoning ceiling, and on \nRvClips\ real phone clips walked through city streets we report zero-shot,
fine-tuned and probe-transfer results for every architecture. Code, both environments, the real-video ingest pipeline
and all checkpoints are released.
\end{abstract}
